# PhotoKamo – Redesign spec: one engine picker, crop, print border, multi-photo

Status: approved design · 2026-11-20
Mockups: `mockups/*.png` (A–I below). Live canvas: https://claude.ai/code/artifact/d35862b2-b86a-4208-9c45-e8718164854e
Repo baseline: `humpreycogay/photokamo` @ `a111f56`

## 0. Summary of decisions

| Area | Decision |
|---|---|
| Modes | **Remove Simple/Advanced.** The engine is the first control in the Look tab. "Presets" is one engine among others. |
| Engine picker | One control, **custom button + popover listbox** (not native `<select>`), grouped *Quick* / *Film simulation*, with size, "Downloaded" badge and one-line description per engine. |
| Tabs | **Look · Adjust · Crop · Frames**, identical for every engine (desktop and mobile). |
| Adjust | Works on top of every engine (today it is ignored in Advanced). |
| Print border | Lives in **Frames**, as the *Paper print* frame with its own settings. Drawn on the exported image (today it is CSS-only and never exported). |
| Crop | Own tab. Ratios: Original, Free, 1:1, 4:5, 9:16, 2:3, 3:4, 5:7, 16:9, 3:2 + **Swap W×H**. Zoom, drag-to-move, resize handles, Straighten, Rotate 90°, Flip. Shows output px. |
| Multi-photo | Filmstrip; click = view, Ctrl/Cmd-click = toggle, Shift-click = range. Edits go to the **photo in view**; **"Apply to N selected…"** dialog copies chosen parts. Optional **"Edit all selected together (live)"** switch. |
| Crop when applying | Checkbox off by default; copies **ratio only, centered** on each photo. |
| Batch export | "Export N" opens a dialog that **asks each time**: one ZIP or separate files. |

## 1. Current code facts the work depends on

- `js/app.js` holds everything: a single `state` object for **one** image, `snapshot()/restore()` for undo, `state.mode` = `'simple' | 'advanced'`.
- Simple render: `renderImage(image, effectiveAdjustments(), frame, edge)` in `js/renderer.js`.
- Advanced render: `module.render(bitmap, advParams(), {quality})` in the engine's Worker, then `frameCanvas(bitmap, frame)`. **`state.edits` are not applied.**
- The white "paper" around Advanced previews is CSS (`body.is-advanced .canvas-wrap { padding: var(--print-border); background: var(--paper) }` in `css/styles.css`), toggled by `module.showsPaper(params)`. `renderAdvancedExport()` does **not** draw it, so preview ≠ export.
- Desktop CSS hides `.control-tabs` and `.panel-body` when `body.is-advanced` (styles.css ~L340), so Adjust and Frames are unreachable in Advanced.
- `pickLook()` silently switches back to Simple and toasts.
- Frames: `frames` in `js/presets.js` (`none`, `classic`, `instant`, `sprocket`), drawn by `frameLayout()`/`frameCanvas()` in `renderer.js`.
- Engine registry: `js/engines/registry.js` (`label`, `description`, `approxDownload`, `load`). Saved engines list: `js/engines/engine-files.js → savedEngines()`.
- Advanced controls are generated by `js/advanced-ui.js` (`buildAdvanced`, `syncAdvanced`) from each engine's `sections`.
- No build step, no runtime dependencies, served as static files.

## 2. Target data model

Per photo (replaces the single-image fields of `state`):

```js
photo = {
  id, file, filename, width, height,          // source; decode lazily
  image: null, bitmap: null, thumb: null,      // decoded only for the photo in view (+ thumb always)
  settings: {
    look: { engine: 'presets' | 'spektrafilm-rs' | 'negs' | 'duxun',
            presetId: 'original', strength: 100,           // used when engine === 'presets'
            engineParams: { [engineId]: params }, myLookId: null },
    edits: {},                                             // Adjust deltas, all engines
    crop: { ratio: 'orig', swapped: false, x: .5, y: .5,   // center, normalised to source
            w: 1, h: 1, zoom: 1, rotate: 0, flip: false, straighten: 0 },
    frame: { id: 'none' | 'paper' | 'classic' | 'instant' | 'sprocket',
             border: { size: 'classic', width: 5, bottom: 4, color: 'warm', matchPaper: true } }
  },
  undo: [], redo: [],                                      // per photo, max 50
  render: { status: 'idle'|'queued'|'rendering'|'done'|'error', progress: 0, key: '' }
}
app = { photos: [], activeId, selected: Set<id>, liveEdit: false, tab: 'look', ... UI-only fields }
```

- `snapshot()` becomes `structuredClone(photo.settings)`.
- Migration: old snapshots / "My looks" with `mode: 'simple'` → `look.engine = 'presets'`; `mode: 'advanced'` → keep `engine`. Looks saved before the Engine dropdown use `legacyEngineId` (already in registry.js).

## 3. Render pipeline (all engines)

```
source ─► crop/rotate/flip/straighten ─► LOOK ─► ADJUST ─► FRAME (+ paper border)
                                        presets: adjustments(preset × strength)      ┐ one processPixels pass
                                        engine:  module.render(croppedBitmap)        ┘ then processPixels(edits) if any
```

- New `cropSource(image, crop, maxEdge)` in `renderer.js` returns a canvas/ImageBitmap; cache per photo by `JSON.stringify(crop)+edge`.
- Presets: unchanged math (`original + (look − original) × strength + edit`).
- Engines: run on the cropped bitmap; then if `edits` is non-empty, apply `processPixels` with `defaultAdjustments + edits`.
- Full-quality render & export use the same pipeline at full size. `fullRenderKey` must include `crop` and `edits`.
- "Hold to compare" shows the cropped original with the same frame.

## 4. Screens and acceptance criteria

### A/B · Look tab with engine picker — `mockups/A-look-presets-multiselect.png`, `B-look-film-engine.png`, `C-engine-picker.png`
- Mode switch (both `.mode-switch` instances in `index.html`) and its CSS are removed.
- Look tab top: label "Engine" + button showing icon, engine name, one-line status (`Presets · 20 quick looks · instant · nothing to download`, or `Ready · 52 films · WebGPU`, or `Downloading… 42%`).
- Popover (`role="listbox"`, opened by the button with `aria-haspopup="listbox"`, `aria-expanded`):
  - Group **QUICK**: Presets.
  - Group **FILM SIMULATION · RUNS ON YOUR DEVICE**: Negs, DuXun, Spektrafilm (registry order may change; list from `engines`).
  - Each row: name, description, right side = `approxDownload` or a green **Downloaded** badge (from `savedEngines()`), check on the current one. Negs without WebGPU shows "Slower here (no WebGPU)".
  - Keyboard: ↑/↓ move, Home/End, Enter/Space choose, Esc closes and returns focus to the button. Click outside closes.
- Engine = Presets → below the picker: look card (group, name, Strength), filter chips, Surprise me, look grid, then **My looks** (saved film-engine looks, tagged with the engine name, e.g. "NEGS").
- Engine = a film engine → below the picker: Film / Paper selects + Strength card, then the engine's pipeline sections (`advanced-ui.js` output, collapsed), "Save as my look", credit line.
- Picking a preset tile switches the engine to Presets **without a toast**; picking a "My look" tile switches to its engine.
- Switching engine keeps Adjust edits, Crop and Frame. It is one undo step.
- ✅ Done when: Adjust, Crop and Frames tabs are reachable with every engine on desktop and mobile; no `is-advanced` class remains; undo restores the previous engine.

### Adjust (all engines)
- ✅ Adjust sliders visibly change the output for Negs/DuXun/Spektrafilm previews **and** exports.
- ✅ With no edits, engine output is byte-identical to before (no extra processPixels pass).

### F · Frames tab + print border — `mockups/F-frames-print-border.png`
- `frames` gains `{ id: 'paper', name: 'Paper print', description: 'White print border' }`. Order: None, Paper print, Classic, Instant, Film strip.
- When `frame.id === 'paper'` show **Print border** section:
  - Size radiogroup: None 0 · Thin 2.5% · Classic 5% · Gallery 9% (of the short edge) — selecting sets `width`.
  - Width slider 0–15 %, "Extra at bottom" slider 0–15 %.
  - Paper color radiogroup (44 px swatches, `aria-label`): Bright white `#fbfbf9`, Warm `#f4efe4`, Aged `#e6dcc6`, Black `#161614`.
  - "Match paper tint to the chosen print paper" checkbox (only enabled for film engines whose params name a print paper; derive a tint from the paper, fallback Warm).
- `frameLayout()` handles `'paper'` using these values; drawn in preview **and** export.
- Default: choosing a film engine whose `showsPaper(params)` is true and whose frame is `none` sets `frame.id = 'paper'` once (preserves today's look). The user can change it.
- Remove the CSS paper (`--print-border`, `.canvas-wrap` padding/background under `.is-advanced`, `no-paper` class); the stage background can stay mid-grey for film engines.
- ✅ Export of a Negs photo with Paper print shows the border; changing width/bottom/color updates preview and export.

### G/H · Crop tab — `mockups/G-crop-desktop.png`, `H-crop-mobile.png`
- Tab order Look · Adjust · Crop · Frames. Mobile bottom nav gets a 4th item "Crop".
- While Crop is open: stage shows the full (uncropped, look applied at preview quality is fine; plain source acceptable for speed) photo dimmed to ~28 % outside the crop box, crop box with rule-of-thirds lines, 4 corner + 4 edge handles. Frame is hidden while cropping.
- Ratios (radiogroup, icon + label): Original, Free, 1:1, 4:5, 2:3, 5:7, 9:16, 3:4, 16:9, 3:2. **Swap W×H** button swaps the active ratio (disabled for 1:1 / Original / Free).
- Choosing a ratio fits the largest crop of that ratio inside the image, centered on the current crop center.
- Interactions: drag inside the box = move photo under the box (clamped so no empty area); wheel / pinch / Zoom slider (1×–3×) = zoom around box center; handles resize (fixed ratio keeps aspect; Free resizes freely; minimum 64 px source). Arrow keys move 1 % (Shift = 10 %) when the box has focus; `+`/`-` zoom.
- Straighten slider −45°…45° (auto-zooms so no empty corners), Rotate 90° clockwise, Flip horizontal, Center, Reset crop, Done (returns to the previous tab).
- "Output W × H px" updates live (source px after crop).
- Crop stored normalised (0–1) so it survives preview size changes and full-res export.
- ✅ Export dimensions equal the shown Output size (before frame); undo/redo covers every crop change (commit on pointer-up, not every move).

### D · Apply to selected — `mockups/D-apply-to-selected.png`
- Shown from "Apply to N other selected…" (bottom of the panel) when ≥ 2 photos are selected.
- Checkboxes (remember last choice in `localStorage` key `photokamo:apply-parts`):
  Look ✓ · Adjustments ✓ · Frame ✓ · **Crop ratio ☐** (ratio + swapped only, centered, zoom 1) · Exposure & white balance ☐ (the `exposure`, `temperature`, `tint` keys of `edits`; when unchecked those keys are kept from each target).
- Each line shows a summary of what will be copied (engine · film → paper; changed adjustment names; frame name; ratio).
- Apply = one undo step **per target photo**; toast "Applied to 2 photos. Undo on each photo."
- Targets re-render through the queue (§5).
- **Live switch** "Edit all selected together (live)": when on, every committed change on the photo in view is applied to all selected using the same parts as the last dialog choice; off by default; turns off automatically when selection drops to 1.

### Filmstrip & selection — in A, B, E
- Strip under the stage: 84 px thumbs desktop / 52 px mobile, plus an **Add photos** tile. `role="listbox" aria-multiselectable="true"`, each `role="option"`.
- Click = view (and select only it unless already selected); Ctrl/Cmd-click toggle; Shift-click range; Space toggles focused; Ctrl/Cmd-A select all. Selection bar: "N selected", Select all, Clear.
- States: in view (3 px light ring + "In view" label), selected (accent ring + check), edited dot, render progress bar, error icon.
- Opening several files (file input `multiple`, drag-and-drop of many) appends; the first new photo comes into view. Keep the 40 MB per-file limit; soft cap 50 photos (toast beyond).
- Header Export button reads "Export" (1 selected) or "Export N".
- Only the photo in view keeps a full-size decoded image; others keep `file` + 256 px thumb.

### I · Batch export — `mockups/I-export-batch.png`
- With 1 photo selected: today's export dialog, unchanged.
- With N > 1: title "Export N photos", thumbs, **Download as**: One ZIP file (`photokamo-N-photos.zip`) / Separate files (note: browser may ask to allow multiple downloads). Default = last choice. Format + Quality apply to all. Progress "Rendering full quality k of N". Cancel stops after the current photo.
- ZIP: write a small store-only (no compression) ZIP writer in `js/zip.js` (CRC-32 + local headers + central directory). **No new dependency.** Unique names: `<name>-photokamo.jpg`, add `-2`, `-3` on clashes.
- Web Share: offer "Share" with all files when `navigator.canShare({ files })` is true.

### E · Mobile — `mockups/E-mobile-look.png`, `H-crop-mobile.png`
- Header: ✕, "N selected" (or file name), Save/Save N.
- Filmstrip sits between photo and the bottom sheet.
- Look sheet: engine chip (opens the same listbox as a bottom sheet), current look name, "Apply to N" button, horizontal look row.
- Bottom nav: Look · Adjust · Crop · Frames (all ≥ 44 px targets).

## 5. Render queue (multi-photo)
- One queue, one job at a time per engine Worker; the photo in view always jumps ahead.
- Non-active photos render previews at thumb size (≤ 512 px) for the strip; full quality only on export.
- A settings change on a queued photo replaces its job (dedupe by photo id). Abort uses the existing `AbortController` pattern (`state.renderAbort`).

## 6. Non-functional
- No backend, no network except engine downloads (unchanged). No new runtime dependencies.
- Keyboard and screen-reader accessible (roles above, visible focus, 44 px targets, 4.5:1 text contrast using existing tokens in `css/styles.css`).
- Memory: release `ImageBitmap`s of photos leaving view (`bitmap.close()`).
- Works in current Chrome, Edge, Firefox, Safari; Negs falls back to CPU without WebGPU (unchanged).
